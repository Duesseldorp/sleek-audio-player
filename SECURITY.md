# Security Policy

## Supported versions

Security fixes are provided for the latest released version. Please update to
the current release before reporting an issue.

| Version | Supported |
|---------|-----------|
| 2.5.x   | ✅        |
| < 2.5   | ❌        |

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues.**

Instead, report them privately in one of these ways:

- **GitHub Security Advisories** (preferred):
  [Report a vulnerability](https://github.com/Duesseldorp/sleek-audio-player/security/advisories/new)
- **Email:** kontakt@duesseldorp.de — please put "Sleek Audio Player Security"
  in the subject line

Helpful details to include:

- Affected plugin version and WordPress/PHP version
- A description of the issue and its impact
- Steps to reproduce (a proof of concept helps a lot)
- Whether the issue is already known publicly

## What to expect

- **Acknowledgement:** within 5 days
- **Assessment:** within 14 days you get an evaluation and, if confirmed, a
  planned fix date
- **Fix:** as fast as reasonably possible; critical issues are prioritised over
  everything else
- **Credit:** if you'd like, you'll be credited in the changelog and the
  security advisory — just tell me the name you want to be listed under

Please give me a reasonable window to publish a fix before disclosing the issue
publicly. This is a free plugin maintained by one person in their spare time,
so I appreciate your patience — but security reports always jump the queue.

## Scope

In scope: the plugin code in this repository (PHP, JavaScript, CSS).

Out of scope: vulnerabilities in WordPress core, in other plugins or themes,
in the hosting environment, and issues that require an already-compromised
administrator account.
